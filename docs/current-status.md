# Current status

**Overall maturity: pre-release engineering.** The project is completing Phase 0:
reconciling architecture, repository ownership, schemas, development tooling,
threat coverage, terminology, and public claims.

## Implemented foundations

- Multiple Python service prototypes and shared JSON contracts.
- Unit coverage for orchestration, policy, communications, capabilities, and rendering.
- Docker Compose development topology and native-appliance experiments.
- Semantic multimodal response and accessibility-oriented web foundations.

## Approved, not yet implemented end to end

- Per-person assistant authority and independent key domains.
- Explicit household and relationship context spaces.
- Consolidated six-boundary appliance topology.
- Outbound-first remote channels and assurance escalation.
- Provider-blind encrypted backup and replacement-device restore.
- A supported Ubuntu 24.04 x86_64 appliance installer and update channel.

Phase 1 will not begin until the Phase 0 acceptance evidence is reviewed. Public
pages use **implemented**, **experimental**, **planned**, and **long-term vision**
to distinguish evidence from intent.
